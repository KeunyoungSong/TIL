# TIL (Today I Learned)

이 저장소의 TIL 문서는 “이전 draft 형태” 하나만 쓴다.

---

## 저장소 원칙
- 배운 내용 하나당 파일 하나(루트에 `Markdown` 파일 1개).
- 디렉토리/자산은 만들지 않는다. (검색은 파일명/본문 검색으로 한다)
- 기술 용어/기술 스킬 표기는 영어를 유지한다(예: `Object Detection`, `AP`, `mAP`, `Precision–Recall`).

---

## 문서 형태(유일)
문서는 아래 흐름을 반드시 갖는다.

1) **먼저 목록을 뽑는다**
- 문서 상단에 “TIL 후보 목록(=문서 설계도)”을 불렛으로 쓴다.

2) **목록을 그대로 따라가며 섹션을 채운다**
- “이제 아래 섹션은 위 목록을 순서 그대로 따라간다.” 한 줄을 넣는다.
- 이후 섹션은 목록 순서대로 `## 1) ...`, `## 2) ...`처럼 진행한다.

중요:
- 별도 템플릿(결론/핵심/예시/주의 등)을 강제하지 않는다.
- 목록과 본문 섹션의 1:1 대응(그리고 순서 유지)이 핵심이다.
- 문서 마지막에는 아래 섹션을 **반드시** 넣는다.
  - `## 마지막으로, 기억할 한 문장`
  - 내용은 “내가 이 문서에서 고정하고 싶은 문장 1개”만 쓴다.

---

## 템플릿
새 문서는 `TEMPLATE.md`를 복사해서 시작한다.

---

## 파일 이름
파일명은 날짜로 시작하면 충분하다.

- 권장: `YYYY-MM-DD__키워드,키워드.md`

---

## 작성 흐름(운영)
1. `TEMPLATE.md` 복사
2. 목록(Outline) 작성
3. 목록을 따라 섹션 작성
4. 작성/수정 후 먼저 검토 요청

인덱스는 만들지 않는다.
